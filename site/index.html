    60-Second Setup

    From Cloudflare API token to working VLESS configs

    Follow these four steps after installing DastYab on Linux, macOS, or Windows.

    01.

    Add and verify your token

    Tokens are isolated in mode 0600 under ~/.dastyab/profiles/ and verified directly against Cloudflare.

    token setup 
    dastyab token add cf-main <YOUR_CF_API_TOKEN>
dastyab verify
    02.

    Deploy a VLESS Worker

    Pushes a byte-humanized Worker script and returns your base VLESS share link.

    worker deploy 
    dastyab deploy --preset standard
    03.

    Find verified clean IPs

    Streams candidate Cloudflare IPs, runs TLS/WS health gates, and stops once 5 working IPs pass E2E verification.

    clean-ip scan 
    dastyab find 5
    04.

    Export client configurations

    Render ready-to-import files for Clash, sing-box, or v2rayN / v2rayNG in one step.

    client export 
    dastyab export clash   --output clash.yaml
dastyab export singbox --output config.json
dastyab export v2rayn  --output xray.json
    Frequently Asked Questions

    Technical details and security guarantees

    How does DastYab deploy a Cloudflare Worker VLESS proxy? +
    DastYab uses your Cloudflare API token to upload an edgetunnel VLESS worker with randomized stealth pacing and per-deploy byte humanization. Credentials stay local in ~/.dastyab/ with 0600 permissions.
    Why does clean-IP scanning run a Worker health check first? +
    If your Cloudflare account is suspended or the worker route is broken, scanning thousands of IPs will always return zero results. The step-0 gate diagnoses Worker health before probing edge IPs, saving time and bandwidth.
    Which VLESS clients and platforms are supported? +
    DastYab exports v2rayN / v2rayNG, sing-box, and Clash / Clash.Meta configurations, and ships native static binaries for Linux (x64/ARM64), macOS (Apple Silicon), Windows (x64), plus an Android APK covering all four ABIs.
    How do the AI Studio and Google Flow bridges work? +
    Each helper runs an isolated local SOCKS proxy (port 10850 for AI Studio, 10860 for Flow) with its own dedicated browser profile, optional 2-hop chaining, and country/app-shell verification so normal browsing stays untouched.
